# 💕 Dating Memories Journal

> A beautiful shared timeline app for couples to log their dates with photos, captions, location pins, and mood emojis — building a visual love story over time.

---

## 📌 Project Overview

Dating Memories Journal is a web app where couples create a joint account and collaboratively build a timeline of their shared date memories. Each entry captures:

- 📸 **A photo** from the date
- ✍️ **A one-sentence caption** describing the moment
- 📍 **A location pin** on an interactive map
- 😍 **A mood emoji** to capture the feeling
- 📅 **The date** of the memory

Both partners can add, view, and edit memories from any device.

## 📜 Spec-Driven Development

This project follows [Spec-Driven Development (SDD)](https://roelantd.github.io/spec-kit-workshop/) using the [Spec-Kit](https://github.com/github/spec-kit) framework.

- **Constitution** (`.specify/memory/constitution.md`) — Non-negotiable architectural principles, tech stack decisions, and quality gates
- **Specifications** (`specs/spec.md`) — Feature-by-feature breakdown using Objective → Behavior → Constraints → Verification format
